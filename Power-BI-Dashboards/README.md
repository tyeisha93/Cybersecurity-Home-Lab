# Power BI STIG Compliance Dashboard

Built a compliance dashboard visualizing Windows Server 2019 
Cat I STIG assessment results using Microsoft Power BI.

## Dashboard Contents
- Pie chart showing overall compliance status breakdown
- Stacked bar chart showing each finding by title and status
- Card showing total controls assessed (14)

## Results
- Remediated: 9 findings (64.29%)
- Not a Finding: 4 findings (28.57%)
- Not Applicable: 1 finding (7.14%)
- Open Findings: 0

# Cybersecurity Home Lab

## Overview
Built a virtualized cybersecurity home lab environment 
simulating DoD security operations to develop hands-on 
experience with enterprise security tools.

## Environment
- Windows Server 2019 VM
- Ubuntu Linux Server VM
- Host: Windows Desktop
- Hypervisor: VirtualBox

## Tools Used
- Tenable Nessus Essentials
- DISA STIG Viewer 3.7.0
- DISA SCAP Compliance Checker (coming soon)
- Splunk SIEM (coming soon)

## Projects Completed
- Vulnerability Assessment using Nessus
- STIG Compliance Assessment - Windows Server 2019
- POAM Documentation

## Skills Demonstrated
- Vulnerability Management
- STIG Compliance Checking
- Risk Management Framework (RMF)
- Security Documentation
- System Hardening
